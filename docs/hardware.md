# ハードウェア構成

電磁石電流を時間変化する指令に追従させるため、制御系は指令パタンと帰還値を受け取り、変換器へ操作量を渡す。STM32 で通信・パタン管理・制御演算を扱い、MAX 10 で多数の並列 I/O と外部信号に同期する処理を扱うことを想定した設計である。演算を置くコア、更新周期、SPI フレーム、異常時の出力はソフトウェア・HDL 側の仕様となる。

| 回路 | 実装上の要点 |
| --- | --- |
| U1　STM32H745XIH6 | Cortex-M7/M4。内蔵 MAC から RMII で PHY へ接続し、FMC でパタン用 SDRAM をアクセスする。 |
| U2　SDRAM | CAD の型番は IS42S32400D-6BL。実装メーカーに指定した支給品は **IS42S32400J-6BL**。128 Mbit（4M × 32）の下位 16 本を使うので、アクセス可能容量は **8 MiB**。FMC Bank 2、通常の先頭アドレスは `0xD0000000`。[実装資料](../manufacturing/README.md) |
| U3　LAN8742A-CZ-TR / J5　RJ45 | パタン転送用 Ethernet。PHY は 25 MHz 水晶を使用し、RMII には 50 MHz の基準クロックを供給する。 |
| U5　10M16DCF484I7G | MAX 10。外部 ADC インターフェース、D/A 基板、Duty 指令バスなどを母基板へ接続する。ローカル基準クロックは U13 の 50 MHz。 |
| 基板電源 | 母基板から +3.3 V を受電。U4（MPM3833）で FPGA コア系の 1.2 V、U7（AP2112K）でアナログ PLL 系の 2.5 V を生成する。STM32 は Direct SMPS 構成。 |

## STM32 と MAX 10 の間

| バス | 基板上の配線 | 想定しているデータ方向 |
| --- | --- | --- |
| SPI1 | NSS、SCLK、MOSI | MAX 10 → STM32。STM32 がスレーブ受信する想定 |
| SPI2、SPI3 | NSS、SCLK、MOSI | STM32 → MAX 10 |
| SPI4 | NSS、SCLK、MOSI、MISO | 双方向 |

SPI 約 20 MHz、SDRAM の SDCLK 約 100 MHz は技術説明書の設計目標。別途配線した READY、FAULT、IRQ、HEARTBEAT で状態を通知できる。旧パタン入力も J7 に残っているため、旧パタンと SDRAM 再生のどちらを電流指令源にするかは制御側で選択する。

## 基板の取り付けと保守端子

外形は 145.05 × 68.40 mm。裏面の Hirose FX10A 系コネクタ 4 個を母基板に挿す。コネクタ中心の間隔は横 41 mm、縦 44 mm。子基板の外形は ACM-205（86 × 54 mm）より大きく、筐体や周辺部品との干渉には実装状態での確認が必要となる。

| コネクタ | 用途 |
| --- | --- |
| J1 | STM32 HRTIM の出力 D1/D2・E1/E2 とフォルト入力 FLT5 |
| J3 | STM32 内蔵 ADC3 のアナログ入力 2 本（PC2_C、PC3_C）。母基板の光受信 6 系統は J10 を使用する。 |
| J4 / J6 | それぞれ STM32 の SWD、MAX 10 の JTAG。J4 は試作時に加工ケーブルで書き込んだ。[J4 の 1 番端子と基板パッドの対応](errata.md) |

## KiCad で開く

設計元は KiCad 10.0.6。[プロジェクト](../hardware/kicad/JPARC_PS_FB_BOARD.kicad_pro)を開くと、トップシートから STM32H7、SDRAM、Ethernet、MAX10、Interface の各シートをたどれる。プロジェクト用のシンボル、フットプリント、ライブラリテーブル、DRC ルールを設計と同じディレクトリに収録した。

一部の部品は別ライブラリ名 `Kurimoto` を参照する。そのライブラリ原本は配布元 ZIP に含まれていない。配置済みのシンボルとランド形状は回路図・PCB 内に保存されている。ライブラリから部品を更新するときは参照先と形状の照合が必要になる。
