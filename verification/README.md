# 設計検証記録

ACM-205 を置き換えた後の動作確認は [実機試験](bench-tests.md)、書き込み・実装で判明した修正点は [既知不具合と次回改版](../docs/errata.md) にまとめた。

以下は設計元に収録された KiCad 10.0.6 の設計時記録（2026-09-17）。基板データと検査記録に記載された PCB の SHA-256 は一致する。

| 記録 | 結果 |
| --- | --- |
| [DRC](final_drc.json) | エラー 0、未配線 0。ライブラリ関連の警告 205 件、回路図との照合で U4 の DNC ピンに関する警告 2 件。 |
| [PCB 接続検査](native_audit.json) | 469/469 ネットの導通、MAX 10 とコネクタ間の 212/212 接続。接点ごとに FPGA ボールとネット名を記録。 |
| [配線形状](quality.json) | 微小接触、重複配線、信号の孤立銅箔、端子外の行き止まりはいずれも 0。残る分岐と BOOT0 配線の曲がりは記録内に記載。 |
| [CAM](cam_validation.json) | 裸基板 Gerber 13 枚、PTH 1,798 穴、NPTH 10 穴に対する検査記録。U3 の 4 穴でマスク開口・ペーストとの重なりがないことを確認。 |
| [ネットリスト](final_netlist.xml) | 現行回路図から出力した部品、ピン、ネットの一覧。 |

同梱記録では今回の回路に対する ERC の再実行は行っていない。これらの検査が対象とするのは CAD データと製造出力で、実機での ADC/DAC 通信、電流追従、Ethernet インピーダンスの測定結果は含まない。

収録時に、整理後のトップ回路図から KiCad CLI 10.0.5 でネットリストを再出力し、1,883 個の部品端子について参照番号・ピン番号・ネット名の組が同梱ネットリストと一致することを確認した。PCB から外形層も出力できた。[ADC/DAC の端子表](../docs/interfaces.md)にある 34 本は、回路図ネットリストと PCB 接続検査の両方で J10 接点・U5 ボールの組を照合した。
